# Mission

## What We Do

Free, open-source platform for practising technical assessment-style quizzes across engineering domains and difficulty levels. Community-contributed questions — anyone can add topics, categories, or problems via pull request.

---

## Who We Serve

**Primary user:** Software engineer or developer preparing for a job that requires passing a technical assessment.

**Out of scope:** Non-technical users learning to code for the first time.

---

## The Problem

No free platform covers assessment-style practice at this breadth. Alternatives require:
- Payment to access or extend content
- Registration just to start practising
- Accepting locked-down question sets with no way to contribute

---

## Why Existing Alternatives Fall Short

| Problem | Alternatives | AssesLab |
|---|---|---|
| Cost | Paid tiers, freemium limits | Free, always |
| Extensibility | Closed content | Open, PR-based contributions |
| Privacy | Sign-up required to start | Guest access, no friction |
| Breadth | Fixed categories | Community-grown |

---

## Target Audience

### Personas

| Persona | Description |
|---|---|
| **Junior** | ~20yo, some experience, low confidence in assessment performance |
| **Mid** | Working developer, no prior formal assessment experience |
| **Senior** | Experienced engineer, needs a warm-up before a big interview |

### Roles

| Role | Access |
|---|---|
| **Guest** | Run quizzes locally or online, no cloud persistence or shareable results/profile |
| **Registered** | Results history, badges, shareable profile and results |

---

## Success Criteria

### User outcome
User runs the project locally (or visits the site) and starts practising immediately — zero friction, no paywall, no required sign-up.

### Business outcome
Project reaches organic virality. Registered users earn badges and build shareable profiles. Profiles become signals companies can use when hiring. Accept donations for core mantainers. 

Future: 
- Project sponsor tiers.
- Offer free subscription to newsletter.
- Partnerships with hiring platforms.

### KPIs (first signal)

1. **Daily active users** — are people coming back?
2. **Quiz completions** — are sessions finishing, not abandoning?
3. **Retention / community joins** — stars, forks, Discord/community members
