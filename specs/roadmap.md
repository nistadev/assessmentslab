# Roadmap

Phases are intentionally small — each one is a shippable slice of work, independently reviewable and testable.

---

## Phase 1 — Core Quiz (current)

- Domain + topic + difficulty selection
- Shuffled multiple-choice quiz
- Immediate answer feedback + explanation
- Results summary screen
- Guest-only, no persistence
- Light / dark theme
- Run locally or deploy statically (Vercel)

## Phase 2 — Community + Contributions

- Contributor guide + question submission flow
- GitHub-based PR review for new questions

## Phase 3 — Auth + Persistence

- Google / GitHub OAuth login
- Save quiz results per user
- Result history screen
- Guest → registered upgrade path (no data loss)

## Phase 4 — Badges + Profiles

- Badge system tied to quiz completions and streaks
- Public shareable profile page (`/u/:username`)
- Profile shows domains covered, score trends, badges earned
